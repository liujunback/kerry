# 语言使用规范（强制）

## 1. 输出语言禁令
🚫 **所有回复内容必须使用简体中文书写**  
- 包括但不限于：代码注释、错误解释、方案说明、技术建议  
- 禁止在任何非代码块的位置出现英文句子或英文段落  
- 禁止中英文混写（例如：“这个 function 的作用是……”）

## 2. 唯一例外
⚠️ 仅限以下情况可保留英文：
- **专业术语**：如 API、JSON、HTTP、React、TypeScript 等标准技术名词  
- **代码本身**：变量名、函数名、关键字等代码内容不受此限  
- **链接/引用**：文档链接、官方名称等原始内容

## 3. 术语处理（必须执行）
当使用英文术语时，**必须在其后紧跟中文解释**  
✅ 正确示例：  
“这个 API（应用程序接口）的作用是……”  
“我们需要定义一个 Interface（接口）……”

❌ 错误示例：  
“这个 API 的作用是……”（缺少解释）  
“我们需要定义一个 Interface……”（缺少解释）

## 4. 违反后果
若回复中出现未经解释的英文术语或整句英文，视为 **违反核心输出规范**，用户有权要求立即重写。

## 5. 文本内容规范
✅ **所有用户界面文本只先做中文（简体）的国家化**  

## 6. 页面UI规范
✅ **所有界面简约风，不要太多颜色**
