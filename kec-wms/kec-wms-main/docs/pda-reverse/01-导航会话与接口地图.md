# PDA（手持端）导航会话与接口地图

## 1. 覆盖范围

本文件覆盖 PDA（手持端）的应用骨架：

- `MainActivity.kt`
- `MainViewModel.kt`
- `PdaRoutes.kt`
- `PdaScreenSpec.kt`
- `ApiPaths.kt`
- `NetworkModule.kt`
- `AuthInterceptor.kt`

## 2. 页面路由

当前 `PdaRoutes`（PDA路由）集中定义这些可跳转页面：

- `HOME`：工作台首页
- `ASN_SIGN_IN`：ASN（入库通知单）签收
- `ASN_SCAN`：ASN（入库通知单）扫描
- `SKU_RECEIVING`：SKU（商品）收货
- `CONTAINER_RECEIVING`：容器收货
- `PUTAWAY`：上架入口
- `PUTAWAY_SKU`：SKU（商品）上架
- `PUTAWAY_CONTAINER`：容器上架
- `PICKING`：拣货
- `CHECKING`：签出
- `SHIPPING`：预留发货页面
- `MANIFEST_MOUNT`：集运挂载
- `CYCLE_COUNT`：盘点
- `TRANSFER`：库存转移
- `INVENTORY_QUERY`：库存查询

`PdaScreenSpec`（PDA页面规格）是当前页面注册中心。每个页面在这里声明渲染函数、返回策略和 ViewModel（视图模型）接入方式，因此新增 PDA 页面不能只在 `MainActivity` 中临时跳转。

## 3. 登录和会话

PDA（手持端）会话由 `MainActivity`、`MainViewModel`、`AuthRepository`（认证仓储）和 `LoginPreferences`（登录偏好存储）共同维护：

1. 登录页提交租户、用户名、密码。
2. 后端返回 token（令牌）、用户信息、权限和仓库信息。
3. 本地保存 token（令牌）、用户、仓库和权限。
4. 如果账号绑定多个仓库，进入仓库选择页；仓库确认后进入 `HOME`。
5. `AuthInterceptor`（认证拦截器）给请求加认证信息，并在会话过期时发出 `SessionExpired`（会话过期）事件。
6. `MainActivity` 收到会话过期事件后重置页面到首页并回到登录态。

## 4. 网络层

当前网络层是 Retrofit（网络请求库）+ OkHttp（HTTP客户端）：

- `NetworkModule.kt` 创建 Retrofit（网络请求库）服务。
- `ApiPaths.kt` 统一维护接口路径。
- `AuthApi`、`AsnApi`、`PutawayApi`、`PickingApi`、`CheckoutApi`、`ManifestMountApi`、`InventoryApi`、`InventoryCountApi` 分别承载不同业务接口。
- Repository（仓储）层把接口响应包装成 Kotlin（安卓语言）里的 `Result`（结果类型）。
- UseCase（用例）层做轻量参数校验，再交给 Repository（仓储）层。

## 5. 后端 PDA（手持端）接口入口

后端 PDA（手持端）接口集中在：

- `backend/src/app/api/pda/v1/auth/*`
- `backend/src/app/api/pda/v1/inbound/*`
- `backend/src/app/api/pda/v1/outbound/*`
- `backend/src/app/api/pda/v1/inventory/*`
- `backend/src/app/api/pda/v1/containers/*`
- `backend/src/app/api/pda/v1/sku/*`

Android（安卓）端 `ApiPaths`（接口路径常量）目前覆盖：

- 登录、当前用户、二维码令牌登录
- ASN（入库通知单）签收、查询、收货、收货完结
- 容器查询、容器明细、容器重置、容器关闭
- 上架单查询、容器上架、库位查询、上架提交
- 库存查询、库存调整、盘点批次执行
- 拣货任务、绑定容器、提交拣货、完成拣货
- 签出校验、签出扫描、签出确认、待签出列表
- 集运校验、集运扫描、集运确认

## 6. 体验约束

当前 PDA（手持端）有明确的共享体验约束：

- 用户可见文案应使用 string resource（字符串资源），不应硬编码在 Kotlin（安卓语言）或 Compose（声明式界面）代码里。
- 扫码输入优先复用 `PdaTextField`（PDA输入框），由共享组件处理扫码枪回车。
- 成功、失败反馈优先使用 `PdaFeedbackBanner`（PDA反馈条），不要把 toast（短提示）作为主要反馈。
- 声音和震动走 `PdaSoundManager`（声音管理器）和 `PdaHapticManager`（震动管理器），页面只发一次性 UI event（界面事件）。
- 自动聚焦要通过安全 helper（辅助函数），避免目标输入框尚未挂载时直接 `requestFocus`（请求焦点）。
