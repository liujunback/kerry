# 入库超时看板

## 功能概述

入库超时看板用于监控和分析入库作业的进度和效率，帮助仓库管理人员及时发现超时问题，优化入库流程。

## 业务背景

在仓储作业中，入库效率直接影响库存周转和客户满意度。通过实时监控各个入库环节的状态和数量，可以：
- 及时发现入库瓶颈和超时问题
- 按客户维度分析入库效率
- 优化资源配置和作业计划
- 提升整体入库作业效率

## 核心功能

### 1. 查询条件

#### 1.1 目标上架时间
- **字段名称**：expected_putaway_date
- **数据类型**：日期范围
- **说明**：支持选择单个日期或日期范围，查询该时间段内计划上架的 ASN
- **默认值**：当天及未来 7 天

#### 1.2 客户筛选
- **字段名称**：client_id
- **数据类型**：下拉多选
- **说明**：支持选择一个或多个客户，查看特定客户的入库情况
- **默认值**：全部客户

### 2. 看板展示

#### 2.1 展示维度

**横向维度**：目标上架时间
- 按日期分组显示（如：2026/01/28、2026/01/06）
- 最右侧显示"汇总"列，统计所有日期的总计

**纵向维度**：ASN 状态
- 已签收（通过 signed_at 字段判断）
- 收货中
- 收货完成
- 上架中
- 汇总（最后一行，统计所有状态的总计）

#### 2.2 展示指标

每个单元格显示三个指标：

1. **IC (Item Count)**
   - 说明：ASN 单据数量
   - 计算方式：COUNT(DISTINCT asn_id)
   - 显示格式：整数

2. **PCS (Pieces)**
   - 说明：商品件数（SKU 数量）
   - 计算方式：SUM(expected_qty) 或 SUM(received_qty)
   - 显示格式：整数

3. **CBM (Cubic Meter)**
   - 说明：体积（立方米）
   - 计算方式：SUM(expected_qty * unit_volume_m3)
   - 显示格式：小数点后 3 位

#### 2.3 状态说明

| 状态 | 说明 |
|------|------|
| 已签收 | ASN 已签收（通过 signed_at 字段判断，signed_at IS NOT NULL） |
| 收货中 | 货物正在收货 |
| 收货完成 | 收货完成，等待上架 |
| 上架中 | 部分商品已上架，部分还在上架中 |

**注意**：ASN 表没有独立的"已签收"状态字段，但有 `signed_at`（签收时间）字段。当 `signed_at` 不为空时，表示该 ASN 已签收。已签收的 ASN 会单独统计显示。

### 3. 数据统计规则

#### 3.1 按目标上架时间分组
- 使用 `asn.expected_putaway_date` 字段进行分组
- 如果该字段为空，则不显示在看板中

#### 3.2 按状态分组
- 使用 `asn.status` 字段进行分组
- 已签收状态通过 `asn.signed_at` 字段判断（不为空则为已签收）
- ASN 状态值（看板显示）：
  - 已签收：signed_at IS NOT NULL（独立统计）
  - 收货中
  - 收货完成
  - 上架中
- 不显示的状态：
  - 待收货（不在看板中显示）
  - ASN完成（不在看板中显示，因为已完成）

#### 3.3 汇总计算
- **日期汇总**：每个日期列的最后一行显示该日期所有状态的汇总
- **状态汇总**：最右侧"汇总"列显示所有日期该状态的汇总
- **总汇总**：右下角单元格显示所有日期、所有状态的总汇总

### 4. 超时标识

#### 4.1 超时判断规则
- 如果当前时间 > expected_putaway_date，且 ASN 状态不是"ASN完成"，则标记为超时
- 超时的数据用红色字体显示

#### 4.2 超时提醒
- IC 列：如果有超时 ASN，数字显示为红色
- 支持点击超时数字，查看超时 ASN 明细列表

## 数据来源

### 主要数据表

1. **asn** (ASN 主表)
   - asn_number：ASN 单号
   - warehouse_id：仓库 ID
   - client_id：客户 ID
   - status：ASN 状态
   - expected_putaway_date：目标上架日期
   - signed_at：签收时间（用于判断是否已签收）
   - total_expected_qty：预期总数量
   - total_received_qty：已收货总数量
   - total_putaway_qty：已上架总数量

2. **asn_line** (ASN 行明细表)
   - asn_id：ASN ID
   - sku_code：SKU 编码
   - expected_qty：预期数量
   - received_qty：已收货数量
   - putaway_qty：已上架数量

3. **sku** (SKU 主表)
   - id：SKU ID
   - sku_code：SKU 编码
   - unit_volume_m3：单位体积（立方米）

4. **client** (客户表)
   - id：客户 ID
   - client_name：客户名称

## SQL 查询示例

```sql
-- 入库超时看板查询
SELECT
    DATE_FORMAT(a.expected_putaway_date, '%Y/%m/%d') AS target_date,
    CASE
        WHEN a.signed_at IS NOT NULL THEN '已签收'
        ELSE a.status
    END AS status_display,
    COUNT(DISTINCT a.id) AS ic_count,
    SUM(al.expected_qty) AS pcs_count,
    SUM(al.expected_qty * COALESCE(s.unit_volume_m3, 0)) AS cbm_volume,
    -- 超时标识
    CASE
        WHEN NOW() > a.expected_putaway_date AND a.status NOT IN ('ASN完成')
        THEN 1
        ELSE 0
    END AS is_timeout
FROM asn a
INNER JOIN asn_line al ON a.id = al.asn_id
LEFT JOIN sku s ON al.sku_code = s.sku_code
WHERE a.expected_putaway_date IS NOT NULL
  AND a.expected_putaway_date BETWEEN :start_date AND :end_date
  AND a.status NOT IN ('待收货', 'ASN完成')  -- 排除待收货和已完成的ASN
  AND (:client_ids IS NULL OR a.client_id IN (:client_ids))
GROUP BY
    a.expected_putaway_date,
    status_display,
    is_timeout
ORDER BY
    a.expected_putaway_date ASC,
    FIELD(status_display, '已签收', '收货中', '收货完成', '上架中');
```

## 界面设计

### 1. 查询区域
- 目标上架时间：日期范围选择器
- 客户：下拉多选框
- 查询按钮：触发数据查询
- 导出按钮：导出 Excel 报表

### 2. 看板区域
- 表格形式展示
- 表头：目标上架时间（横向）
- 行头：ASN 状态（纵向）
- 单元格：IC / PCS / CBM 三个指标
- 超时数据：红色字体显示
- 可点击单元格：查看明细数据

### 3. 明细弹窗
点击单元格后，弹出明细列表，显示：
- ASN 单号
- 客户名称
- 预期数量
- 已收货数量
- 已上架数量
- 目标上架时间
- 当前状态
- 超时时长（如果超时）

## 权限控制

- 仓库管理员：可查看所有客户的入库看板
- 客户用户：只能查看自己的入库看板
- 操作员：可查看分配给自己仓库的入库看板

## 性能优化

1. **索引优化**
   - asn 表：(expected_putaway_date, status, client_id)
   - asn_line 表：(asn_id, sku_code)

2. **缓存策略**
   - 看板数据缓存 5 分钟
   - 客户列表缓存 30 分钟

3. **分页加载**
   - 如果日期范围过大，建议限制在 30 天内
   - 明细列表支持分页加载

## 扩展功能（可选）

1. **趋势分析**
   - 显示近 7 天/30 天的入库效率趋势图
   - 对比不同客户的入库效率

2. **预警设置**
   - 设置超时预警阈值
   - 自动发送超时提醒通知

3. **钻取功能**
   - 点击单元格，钻取到 ASN 明细
   - 支持导出明细数据
