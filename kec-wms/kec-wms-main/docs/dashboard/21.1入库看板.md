## 一、概述 / Part I: Overview

<!-- @AI-CONTEXT: Overview of inbound dashboard functionality -->

### 1.1 功能定位

**入库看板 (Inbound Dashboard)** 是 WMS 系统的实时监控工具，用于：

- 📊 **实时监控**：展示入库作业的实时进度和状态
- 🔍 **快速定位**：快速识别异常和瓶颈环节
- 📈 **数据分析**：提供货量统计和完成率分析
- ⚡ **决策支持**：为运营管理提供数据支撑

### 1.2 业务价值

**对运营管理的价值**：
- ✅ 实时掌握入库作业进度
- ✅ 及时发现和处理异常
- ✅ 优化资源配置和人员调度
- ✅ 提升入库作业效率

**对客户的价值**：
- ✅ 透明化入库进度
- ✅ 预估上架完成时间
- ✅ 提升服务体验

## 三、货量统计 / Part III: Cargo Volume Statistics

<!-- @AI-CONTEXT: Cargo volume statistics display -->

### 3.1 在途货量

**在途件数 (In-Transit Pieces)**

```
定义：已创建 ASN 但尚未到达仓库的货物数量
计算公式：
  在途件数 = SUM(asn_line.expected_qty)
  WHERE asn.status IN ('待收货')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

**在途体积 (In-Transit Volume)**

```
定义：在途货物的总体积（立方米）
计算公式：
  在途体积 = SUM(asn_line.expected_qty * sku.unit_volume_m3)
  WHERE asn.status IN ('待收货')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

### 3.2 到仓货量

**到仓件数 (Arrived Pieces)**

```
定义：asn已签收但尚未完成上架的货物数量
计算公式：
  到仓件数 = SUM(asn_line.received_qty)
  WHERE asn.status IN ('收货中', '收货完成', '上架中')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

**到仓体积 (Arrived Volume)**

```
定义：到仓货物的总体积（立方米）
计算公式：
  到仓体积 = SUM(asn_line.received_qty * sku.unit_volume_m3)
  WHERE asn.status IN ('收货中', '收货完成', '上架中')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

### 3.3 待上架货量

**待上架件数 (Pending Putaway Pieces)**

```
定义：已收货但尚未完成上架的货物数量
计算公式：
  待上架件数 = SUM(asn_line.received_qty - asn_line.putaway_qty)
  WHERE asn.status IN ('收货完成', '上架中')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

**待上架体积 (Pending Putaway Volume)**

```
定义：待上架货物的总体积（立方米）
计算公式：
  待上架体积 = SUM((asn_line.received_qty - asn_line.putaway_qty) * sku.unit_volume_m3)
  WHERE asn.status IN ('收货完成', '上架中')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

### 3.4 上架完成率

**上架完成率 (Putaway Completion Rate)**

```
定义：已完成上架的货物占到仓货物的百分比
计算公式：
  上架完成率 = (已上架件数 / 到仓件数) × 100%

  其中：
  已上架件数 = SUM(asn_line.putaway_qty)
  WHERE asn.status IN ('收货中', '收货完成', '上架中', 'ASN完成')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]

  到仓件数 = SUM(asn_line.received_qty)
  WHERE asn.status IN ('收货中', '收货完成', '上架中', 'ASN完成')
  AND asn.expected_putaway_date BETWEEN [start_date] AND [end_date]
  AND asn.warehouse_id = [selected_warehouse]
```

**显示格式**：
- 圆环图（Donut Chart）
- 中心显示百分比（如：89.45%）
- 下方显示标签："上架完成率 - pcs"

## 四、各环节货量分布 / Part IV: Stage Distribution

<!-- @AI-CONTEXT: Distribution of cargo across different stages -->

### 4.1 正常流程环节

**环节定义与统计规则**：

| 环节 | 代码 | 定义 | 统计规则 |
|-----|------|------|---------|
| **未开始** | NOT_STARTED | ASN已创建但尚未到达 | asn.status = '待收货' |
| **签收** | SIGNING | 货物正在签收 | asn.status = '收货中' AND signing_start_time IS NOT NULL AND receiving_start_time IS NULL |
| **收货** | RECEIVING | 货物正在收货验收 | asn.status = '收货中' AND receiving_start_time IS NOT NULL AND receiving_end_time IS NULL |
| **上架** | PUTTING_AWAY | 货物正在上架 | asn.status = '上架中' |
| **已上架** | COMPLETED | 货物已完成上架 | asn.status = 'ASN完成' |

### 4.2 异常环节

**异常类型定义**：

| 异常环节 | 代码 | 定义 | 统计规则 |
|---------|------|------|---------|
| **签收异常** | SIGNING_EXCEPTION | 签收过程中发现异常 | 存在 receiving_discrepancy 记录且 discrepancy_type = 'SIGNING_ISSUE' |
| **收货异常** | RECEIVING_EXCEPTION | 收货验收发现差异 | 存在 receiving_discrepancy 记录且 discrepancy_type IN ('SHORTAGE', 'OVERAGE', 'DAMAGE') |
| **上架异常** | PUTAWAY_EXCEPTION | 上架过程中发现异常 | putaway_task.status = 'EXCEPTION' |

### 4.3 预警环节

**预警类型定义**：

| 预警环节 | 代码 | 定义 | 触发条件 |
|---------|------|------|---------|
| **订单完结预警** | COMPLETION_WARNING | 接近目标上架时间但未完成 | expected_putaway_date - CURRENT_DATE <= 1 AND asn.status != 'ASN完成' |

### 4.4 环节货量统计

**统计维度**：
- **件数 (Pieces)**：统计 ASN 行的数量总和
- **体积 (Volume)**：统计货物的总体积（可选显示）

**计算示例**：

```sql
-- 未开始环节
SELECT COUNT(DISTINCT asn.id) as asn_count,
       SUM(asn_line.expected_qty) as pieces
FROM asn
JOIN asn_line ON asn.id = asn_line.asn_id
WHERE asn.status = '待收货'
  AND asn.expected_putaway_date BETWEEN '2026-01-30' AND '2026-01-30'
  AND asn.warehouse_id = 'warehouse-uuid';

-- 收货异常环节
SELECT COUNT(DISTINCT asn.id) as asn_count,
       SUM(asn_line.expected_qty) as pieces
FROM asn
JOIN asn_line ON asn.id = asn_line.asn_id
JOIN receiving_discrepancy rd ON asn.id = rd.asn_id
WHERE rd.discrepancy_type IN ('SHORTAGE', 'OVERAGE', 'DAMAGE')
  AND asn.expected_putaway_date BETWEEN '2026-01-30' AND '2026-01-30'
  AND asn.warehouse_id = 'warehouse-uuid';
```

## 五、数据计算规则 / Part V: Calculation Rules

<!-- @AI-BUSINESS-RULE: Data calculation rules -->

### 5.1 数据刷新频率

**实时刷新**：
- 不需要实时刷新，每次查询时获取最新数据即可


### 5.2 数据一致性

**统计口径**：
- 所有统计以 **ASN 行 (asn_line)** 为基础单位
- 件数统计使用 `expected_qty`、`received_qty`、`putaway_qty` 字段
- 体积统计需要关联 SKU 表获取 `unit_volume_m3`

**去重规则**：
- 同一 ASN 可能同时出现在多个环节（如：部分收货、部分上架）
- 环节分布统计按 ASN 单据维度去重
- 货量统计按 ASN 行明细累加

### 5.3 异常处理

**数据缺失处理**：
- SKU 体积为空时，该行不计入体积统计
- ASN 目标上架时间为空时，不纳入看板统计

**边界情况**：
- 到仓件数为 0 时，上架完成率显示为 0%
- 无数据时，显示 "暂无数据"
