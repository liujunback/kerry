# 出库看板

## 功能概述
出库看板用于实时监控仓库出库作业的整体进度和各环节状态，帮助管理人员快速了解出库情况，及时发现和处理异常。

## 界面布局

### 1. 顶部筛选区域

#### 筛选条件
- **客户编码**
  - 类型：输入框
  - 说明：可输入客户编码进行筛选
  - 占位符：请输入客户编码

- **时间类型**
  - 类型：下拉框
  - 选项：截单时间、预计出库时间
  - 说明：选择时间筛选口径
  - 默认值：截单时间

- **时间范围**
  - 类型：时间范围选择器
  - 说明：根据所选时间类型筛选订单
  - 格式：YYYY-MM-DD HH:mm:ss ~ YYYY-MM-DD HH:mm:ss

- **物流渠道**
  - 类型：下拉框 / 输入框
  - 说明：按物流渠道筛选订单
  - 占位符：请选择或输入物流渠道

#### 操作按钮
- **查询**：根据筛选条件查询数据
- **重置**：清空筛选条件，恢复默认状态

### 2. 左侧：单量看板

#### 2.1 基础统计数据

**总单量**
- 显示：数字
- 说明：当前筛选条件下的出库单总数

**待出库**
- 显示：数字
- 说明：尚未完成出库的订单数量

**延误单量**
- 显示：数字（红色标注）
- 说明：超时未完成的订单数量
- 样式：红色警示标注

**出库完成率**
- 显示：百分比 + 圆形进度图
- 计算公式：已完成出库单数 / 总单量 × 100%
- 样式：蓝色圆形进度图

### 3. 右侧：各环节作业看板

#### 3.1 环节列表

各环节按出库流程顺序展示，每个环节显示当前处于该环节的订单数量：

1. **匹配失败**
   - 说明：订单信息匹配失败的数量
   - 显示：数字

2. **换号异常**
   - 说明：换号过程中出现异常的订单数量
   - 显示：数字

3. **出库异常**
   - 说明：出库过程中出现异常的订单数量
   - 显示：数字

4. **待拦截**
   - 说明：需要拦截的订单数量
   - 显示：数字

5. **汇单**
   - 说明：正在汇单的订单数量
   - 显示：数字

6. **拣货**
   - 说明：正在拣货的订单数量
   - 显示：数字 + 进度条（绿色）

7. **分拣**
   - 说明：正在分拣的订单数量
   - 显示：数字

8. **打包**
   - 说明：正在打包的订单数量
   - 显示：数字

9. **移交**
   - 说明：已完成出库并移交的订单数量
   - 显示：数字 + 进度条（绿色）

10. **已拦截**
    - 说明：已拦截的订单数量
    - 显示：数字

11. **取消**
    - 说明：已取消的订单数量
    - 显示：数字 + 进度条（灰色）

#### 3.2 进度条显示规则
- 有订单数量的环节显示进度条
- 进度条长度根据订单数量占比计算
- 颜色规则：
  - 正常流程环节：绿色
  - 取消状态：灰色

## 数据刷新
- 看板数据实时刷新
- 刷新频率：建议每30秒自动刷新一次

## 权限要求
- 需要有出库看板查看权限
- 可按客户维度进行数据权限控制

## 业务规则

### 1. 统计规则
- 总单量 = 所有状态的订单总数
- 待出库 = 未完成移交的订单数（不包括已取消）
- 出库完成率 = 已移交订单数 / （总单量 - 已取消订单数）× 100%

### 2. 延误判定
- 根据订单的预计出库时间与当前时间对比
- 超过预计时间仍未完成移交的订单计入延误单量

### 3. 环节状态
- 每个订单在同一时间只能处于一个环节
- 订单按流程顺序流转
- 异常状态（匹配失败、换号异常、出库异常、待拦截）可在任意环节触发

## 技术实现建议

### 1. 前端展示
- 使用图表组件展示圆形进度图
- 使用进度条组件展示各环节数量
- 实现自动刷新机制

### 2. 数据查询
- 按客户编码筛选
- 按时间类型和时间范围筛选，时间类型支持截单时间、预计出库时间
- 按物流渠道筛选
- 统计各环节订单数量
- 计算完成率和延误情况

### 3. 性能优化
- 使用缓存机制减少数据库查询
- 异步加载数据
- 分页或限制数据量
